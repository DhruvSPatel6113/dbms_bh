# Custom React Hooks Directory (`client/src/hooks/`)

## 1. Directory Purpose & Scope
This directory contains custom React hooks abstracting authentication state, user roles, data query caching, and mutation orchestration for UI components.

## 2. Directory Contents
- `useAuth.js`: Hook managing session tokens, user profiles, and role checks (`isAdmin`, `isLibrarian`).
- `useBooks.js`: Hook managing book query caching and creation/update/deletion mutations.
- `readme.md`: Scope and hook inventory.
- `implementation.md`: Reactive state bindings, caching mechanics, and lifecycle hooks.
