# UI Components Directory (`client/src/components/`)

## 1. Directory Purpose & Scope
This directory contains reusable, stateless presentation components, navigation wrappers, dynamic modal overlays, and visual status badges utilized throughout the application screens.

## 2. Directory Contents
- `Layout.jsx`: Master navigation shell with persistent sidebar, brand headers, and session controls.
- `Modal.jsx`: Accessible modal dialog for forms, actions, and prompts.
- `Badge.jsx`: Color-coded semantic pills for statuses (`Active`, `Overdue`, `ExpiringSoon`, etc.).
- `readme.md`: Scope and component inventory.
- `implementation.md`: Composition patterns, prop contracts, and styling conventions.
